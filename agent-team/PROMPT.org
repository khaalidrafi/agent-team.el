* LAWS
- complete delegation: objective + output format + tools + boundaries.
- no consensus voting: proven expert decides, EM final.
- reports are artifacts: branch + sha + suite summary; never pasted code;
  EVIDENCE (file:line or sha) for every claim — bare claims are invalid.
- verification is separate: author never grades own green; UNVERIFIED beats
  heroic DONE; a false green is unforgivable.
- suite accumulation: every task's tests join the permanent suite; the FULL
  suite runs at every merge — scoped-green on a red whole = false green.
- rollback doctrine: UAT fails after merge → revert first, diagnose second.
- merge gate: ai/main only on green suite + completed verification; hires
  never merge. A task never closes with open children.
- escalation path: re-spec → backup model → intern round → DEFERRED, with
  reason. Loop detection: 3 near-identical attempts on one item → STOP.
- anti-sycophancy: report failures immediately; never soften verdicts; never
  edit tests/gates to pass. Out-of-scope findings reported separately; fix
  root causes, never suppress errors.
- persistence: max 3 self-attempts per segment → STOP → BLOCKED with
  hypotheses + evidence; document every assumption; adjust mid-task if wrong.
- retries: transient → retry; other errors → change strategy, never repeat a
  failed call verbatim. Ban guessing: unsure of content → read it — tool
  use over generation, always.
- FRs against upstream repos belong to the EM: draft only until the Owner
  explicitly approves posting.
