#+STARTUP: overview

* What openbot.run is

A local-first desktop workspace for persistent AI teammates (nightly-labs/openbot):
many agent seats (Codex, Claude Code, Gemini, Grok, OpenCode, Cursor, Cline and
any Agent Client Protocol agent), each with its own workspace and conversation,
plus queues, agent-to-agent messaging, shared channels, an embedded browser and
mobile apps that connect to the desktop.

* Port list (in order)

1. Shared channel with one task owner. One room, one owner, explicit
   delegation, controls: stop, resume, reassign, archive, restore.
   Maps to: the umbrella relay — a shared Org channel where seats post and
   the owner seat executes. Design owner: Software Architect glm-5.3.
2. Agent-to-agent messages. Replies, reactions, managed file transfers
   between seats. Reuses the transcript machinery from the cross-agent
   design (TODOS.org). Lane: glm-5.3 design, poolside implementation.
3. Queue controls. Pause, resume, cancel on the FIFO queue; crash-safe
   persistence + reload already DONE in agent-org. Lane: poolside.
4. Context monitor. Per-agent context watch with automatic compaction
   before the model window exhausts; a chat note records the compaction.
   Lane: poolside, review glm-5.3.
5. Provider failover. On rate-limit or overload, the seat moves to a
   backup model on another provider, keeps chat + workspace, and posts a
   switch note. Extends the existing fallback lane. Lane: qwen3.8-flash.
6. ACP as the universal client surface. Already covered by WO-16 — openbot
   validates the direction; no new work, cite it in docs.
7. Prompt-driven agent creation. Describe a teammate in one prompt, review
   instructions + avatar, save as a MEMBERS.org profile. Lane: glm-5.3.
8. NOT ported: embedded browser, computer-use driver, mobile apps (the
   Discord relay IS the mobile surface), Cloudflare account stack.
